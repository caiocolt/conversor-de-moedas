# 💱 Conversor de Moedas

Conversor de Real (BRL) para Dólar, Euro, Libra e Bitcoin, feito com HTML, CSS e JavaScript puro.

## Como usar
As cotações são buscadas em tempo real na [AwesomeAPI](https://docs.awesomeapi.com.br/). Abra o `index.html` no navegador, digite um valor, escolha a moeda e clique em **Converter**.

## Tecnologias
- HTML5
- CSS3
- JavaScript (fetch, async/await, Intl.NumberFormat)
- AwesomeAPI (cotações em tempo real)
